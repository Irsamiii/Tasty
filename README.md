# Tasty - Restaurant Management System

## Overview

Tasty is a restaurant management platform that connects restaurants and customers through a modern web application.

Restaurants can register on the platform, manage their menus, and keep track of table availability. Customers can browse registered restaurants, view menus, check available tables, and place orders directly through the application.

The project is built with **React.js** for the frontend, providing a responsive and user-friendly experience for both restaurant owners and customers.

---

## Features

### Restaurant Management

- Restaurant registration and onboarding
- Add, edit, and remove menu items
- Manage restaurant information
- Configure the number of available tables
- View and manage customer orders

### Customer Features

- Browse all registered restaurants
- View restaurant menus
- Check table availability
- Place food orders
- Explore restaurant offerings in a simple and intuitive interface

### User Experience

- Responsive design
- Fast and interactive interface
- Easy navigation between restaurants and menus

## Installation

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm or yarn

### Clone the Repository

```bash
git clone https://github.com/Irsamiii/Tasty.git
cd Tasty
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```
